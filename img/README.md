# DOPPIO — images

Every photo slot reads its file from this folder (`data-img`). Drop a file in with the exact name and it shows up. In the console, `doppio.missing()` lists the ones still waiting. Cut-outs (`.png`) have a transparent background and were trimmed to their edges with 3% padding. Originals of everything that was trimmed or cut out are kept untouched in `_raw/`.
